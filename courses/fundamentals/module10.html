Step-by-Step Course Content

✅ Step 1: Understanding the Use Case

In real-world robotics, capturing exact joint movements is vital for automation. This module simulates "training by demonstration" where a human guides the robot, and the robot can replay the movements later.

🧰 Step 2: Controller and Button Mapping

Configure your joysticks and buttons to serve two functions: joystick axes for servo control, and buttons for record and playback.

  • Joystick 1: X → Base (GP26), Y → Shoulder (GP27)
  • Joystick 2: X → Elbow (GP28)
  • Button 1 → GP15
  • Button 2 → GP14

Each joystick controls one or two servos (Base, Shoulder, Elbow). Pressing either button records the current arm pose. Pressing both buttons together starts playback.

💻 Step 3: Initialize Hardware Interfaces

x1 = ADC(Pin(26))
x2 = ADC(Pin(27))
x3 = ADC(Pin(28))

button1 = Pin(15, Pin.IN, Pin.PULL_UP)
button2 = Pin(14, Pin.IN, Pin.PULL_UP)

base_servo = PWM(Pin(2))
shoulder_servo = PWM(Pin(3))
elbow_servo = PWM(Pin(4))

Initialize ADCs for joysticks, buttons with pull-up configuration, and PWM pins for the servos.

🔧 Step 4: Convert Angle to PWM and Smooth Motion

def angle_to_duty(angle):
    us = 500 + (2000 * angle) // 180
    return int(us * 65535 / 20000)

def move_servo(servo, angle):
    servo.duty_u16(angle_to_duty(angle))

def smooth_move(current, target, servo):
    step = 1 if target > current else -1
    for angle in range(current, target + step, step):
        move_servo(servo, angle)
        sleep(0.01)
    return target

Converts desired servo angle to duty cycle.
smooth_move() animates the transition from current to target angle, improving realism.

🕹️ Step 5: Control the Servos Using Joystick Movement

if abs(x1_val - center) > dead_zone:
    base_angle = smooth_move(base_angle, int(x1_val * 180 / 65535), base_servo)

if abs(x2_val - center) > dead_zone:
    shoulder_angle = smooth_move(shoulder_angle, int(x2_val * 180 / 65535), shoulder_servo)

if abs(x3_val - center) > dead_zone:
    elbow_angle = smooth_move(elbow_angle, int(x3_val * 180 / 65535), elbow_servo)

This reads the joystick axes and maps them to servo angles with a dead zone to avoid jitter.

🎯 Step 6: Recording Movements with Button Press

if (b1 == 0 and button1_prev == 1) or (b2 == 0 and button2_prev == 1):
    recorded_steps.append((base_angle, shoulder_angle, elbow_angle))
    print("Recorded:", base_angle, shoulder_angle, elbow_angle)

Each button press records the current servo angles. It allows single-hand operation: use one hand to move the joystick, the other to press the button.

▶️ Step 7: Playing Back the Sequence

if b1 == 0 and b2 == 0 and len(recorded_steps) > 0:
    for step in recorded_steps:
        base_angle = smooth_move(base_angle, step[0], base_servo)
        shoulder_angle = smooth_move(shoulder_angle, step[1], shoulder_servo)
        elbow_angle = smooth_move(elbow_angle, step[2], elbow_servo)
        sleep(0.5)

Both buttons must be held to trigger playback. The robot arm smoothly replays each recorded pose in order.

💡 Understanding Python Lists for Recording Steps

In this module, we use a Python list called recorded_steps to store each set of servo angles you record. A list in Python is a flexible container that can hold multiple items—in this case, each item is a tuple of three angles (base, shoulder, elbow). Every time you press a button to record, a new tuple is added to the list. Later, when you play back, the program loops through this list and moves the servos to each recorded position in order. This is a powerful way to store and replay sequences of actions in robotics and programming!
