🤖 Module 5: Understanding Accelerometer and Gyroscope Readings for Self-Balancing Robots

Intermediate Robotics Course

🧭 Objective

To understand how motion and orientation affect accelerometer and gyroscope readings and how this data can be used to inform robot behavior in a self-balancing system.

🪜 Step-by-Step Breakdown

🔹 Step 1: Introduction to the MPU-9255 Sensor

Discuss the MPU-9255 as a 9-axis IMU sensor (you'll only use accelerometer + gyroscope for now).

  • Communicates via I2C protocol:
  • SCL → GPIO 1
  • SDA → GPIO 0
  • Typical I2C address: 0x68 or 0x69
🔹 Step 2: Accelerometer – How It Works
  • Measures acceleration due to gravity and motion.
  • Outputs ax, ay, az representing the acceleration along each axis.
  • Gravity causes different values when the robot tilts.
  • Pitch ≈ tilt front/back
  • Roll ≈ tilt side/side
🔹 Step 3: Gyroscope – How It Works
  • Measures angular velocity (how fast the robot rotates).
  • Outputs gx, gy, gz in degrees/second.
  • Tracks motion over time, such as sudden turns, shakes, or falling.
🔹 Step 4: Wiring and Interfacing MPU-9255
  • Connect VCC, GND, SCL, SDA to Pico W.
  • Initialize I2C interface and scan for the sensor.
  • Confirm address and check response.
from machine import Pin, I2C

i2c = I2C(0, scl=Pin(1), sda=Pin(0))
print(i2c.scan())  # Expect [104] or [105]
🔹 Step 5: Get Sensor Feedback – Pitch, Roll, Angular Velocity
  • Create a class for MPU9255Sensor with methods:
  • get_accel_gyro()
  • get_pitch()
  • get_pitch_roll()
from machine import I2C, Pin
from mpu9255_sensor import MPU9255Sensor
import time, math

i2c = I2C(0, scl=Pin(1), sda=Pin(0))
imu = MPU9255Sensor(i2c)

while True:
    ax, ay, az, gx, gy, gz = imu.get_accel_gyro()
    pitch = math.atan2(ax, math.sqrt(ay**2 + az**2)) * 180 / math.pi
    roll = math.atan2(ay, math.sqrt(ax**2 + az**2)) * 180 / math.pi
    print(f"Pitch: {pitch:.2f}°, Roll: {roll:.2f}° | Gyro: gx={gx}, gy={gy}, gz={gz}")
    time.sleep(0.5)
🔹 Step 6: Robot Movement vs Sensor Feedback
  • Hold and tilt the robot manually.
  • Watch pitch/roll and gyro data change.
  • Pitch increases when robot tilts forward.
  • Gyro values spike when robot shakes or turns.
  • Record and interpret patterns.
  • When do values stabilize?
  • Can you identify left vs right tilt by roll?
🔹 Step 7: Prepare for Control Logic
  • The data observed here is the foundation for PID control.
  • No correction is applied yet — this is just observation.
  • Next module will use this data to drive motors and maintain balance.
📊 Bonus Task: Plot Sensor Data
  • Optional: Send pitch and roll data via serial and plot in Thonny or Excel.
  • Helps learners visualize how sensor readings evolve in motion.

📦 Part 1: MicroPython Code on Pico W

This code sends pitch, roll, and gyro data over serial:

# mpu_plot_sender.py
from machine import Pin, I2C
from mpu9255_sensor import MPU9255Sensor
import math
import time

i2c = I2C(0, scl=Pin(1), sda=Pin(0))  # Adjust pins if needed
imu = MPU9255Sensor(i2c)

def calculate_pitch_roll(ax, ay, az):
    pitch = math.atan2(ax, math.sqrt(ay**2 + az**2)) * 180 / math.pi
    roll = math.atan2(ay, math.sqrt(ax**2 + az**2)) * 180 / math.pi
    return pitch, roll

while True:
    ax, ay, az, gx, gy, gz = imu.get_accel_gyro()
    pitch, roll = calculate_pitch_roll(ax, ay, az)

    # Print data in CSV format: pitch,roll,gx,gy,gz
    print(f"{pitch:.2f},{roll:.2f},{gx},{gy},{gz}")
    time.sleep(0.1)

🧑‍💻 Part 2: Plotting Script on Your PC (Python + Matplotlib)

Create a Python script on your computer to receive and plot data via the serial port:

# plot_mpu_data.py (run this on your PC)
import serial
import matplotlib.pyplot as plt
from collections import deque

# Update this to your Pico's port (check Thonny or Device Manager)
PORT = 'COM5'
BAUD = 115200

# Create buffers
max_len = 100
pitch_vals = deque([0]*max_len, maxlen=max_len)
roll_vals = deque([0]*max_len, maxlen=max_len)
gx_vals = deque([0]*max_len, maxlen=max_len)

# Set up plot
plt.ion()
fig, ax = plt.subplots()
pitch_line, = ax.plot(pitch_vals, label='Pitch (°)')
roll_line, = ax.plot(roll_vals, label='Roll (°)')
gx_line, = ax.plot(gx_vals, label='Gyro X (°/s)')

ax.set_ylim(-90, 90)
ax.legend()
ax.set_title("MPU-9255 Sensor Data (Real-Time)")
ax.set_ylabel("Angle / Velocity")
ax.set_xlabel("Time")

# Start serial connection
with serial.Serial(PORT, BAUD, timeout=1) as ser:
    while True:
        try:
            line = ser.readline().decode().strip()
            if line:
                parts = line.split(",")
                if len(parts) == 5:
                    pitch, roll, gx, gy, gz = map(float, parts)
                    pitch_vals.append(pitch)
                    roll_vals.append(roll)
                    gx_vals.append(gx)

                    pitch_line.set_ydata(pitch_vals)
                    roll_line.set_ydata(roll_vals)
                    gx_line.set_ydata(gx_vals)

                    pitch_line.set_xdata(range(len(pitch_vals)))
                    roll_line.set_xdata(range(len(roll_vals)))
                    gx_line.set_xdata(range(len(gx_vals)))

                    ax.relim()
                    ax.autoscale_view()
                    plt.pause(0.01)
        except Exception as e:
            print("Error:", e)
