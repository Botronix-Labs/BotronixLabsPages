Module 3: Enhancing GUI with Images, LabelFrames, and Styling

Learn how to make your Python GUI look more professional by adding images, styling text, and grouping related widgets.

Step 1: Load and Display an Image in Tkinter

Concepts Introduced:
  • tk.PhotoImage: Load and display PNG images in your GUI.
  • Label widget: Used to show images or text.
  • Raw string for file paths: Avoids Windows path errors.
import tkinter as tk

root = tk.Tk()
root.title("Robot GUI with Image")
root.geometry("300x300")

# Load a PNG image from the Downloads folder
robot_img = tk.PhotoImage(file=r"C:\\Users\\tonyc\\Downloads\\robot.png")

# Display it in a Label
img_label = tk.Label(root, image=robot_img)
img_label.pack(pady=10)

root.mainloop()
🧠 Explanation:
  • tk.PhotoImage loads PNG/GIF images for use in Tkinter GUIs.
  • Use a raw string (r"...") for Windows file paths to avoid errors.
  • pady=10 adds vertical space around the image.

Step 2: Group Widgets with LabelFrame

Concepts Introduced:
  • LabelFrame: Visually group related widgets with a border and title.
  • .grid() layout: Arrange buttons in a D-pad style.
  • Padding: Controls spacing inside and outside the frame.
frame = tk.LabelFrame(root, text="Controls", padx=10, pady=10, font=("Arial", 12, "bold"))
frame.pack(padx=10, pady=10)

btn1 = tk.Button(frame, text="Forward", width=15)
btn1.grid(row=0, column=1, pady=5)

btn2 = tk.Button(frame, text="Left", width=15)
btn2.grid(row=1, column=0, pady=5)

btn3 = tk.Button(frame, text="Right", width=15)
btn3.grid(row=1, column=2, pady=5)

btn4 = tk.Button(frame, text="Backward", width=15)
btn4.grid(row=2, column=1, pady=5)
🧠 Explanation:
  • LabelFrame creates a visible border and title for related controls.
  • .grid() arranges buttons in a 2D layout (like a D-pad).
  • padx and pady add space inside and outside the frame.

Step 3: Add Fonts and Colors to Labels & Buttons

Concepts Introduced:
  • Font and color styling: Make your GUI more readable and attractive.
  • Button .config(): Change appearance after creation.
title_label = tk.Label(root, text="Pico Otto Control Panel", font=("Arial", 16, "bold"), fg="blue")
title_label.pack(pady=5)

btn1.config(bg="green", fg="white", font=("Arial", 12))
btn2.config(bg="orange", fg="black", font=("Arial", 12))
btn3.config(bg="orange", fg="black", font=("Arial", 12))
btn4.config(bg="red", fg="white", font=("Arial", 12))
🧠 Explanation:
  • Use font, fg (text color), and bg (background) to style widgets.
  • Color coding buttons improves usability and makes controls stand out.
  • Consistent fonts and colors give your GUI a professional look.

Step 4: Mini Project – Styled Robot Controller GUI

Challenge:
  • Add an image of your robot at the top
  • Use a bold, colored title
  • Group movement buttons in a LabelFrame
  • Style the background and add padding for a polished look
import tkinter as tk

root = tk.Tk()
root.title("Pico Otto Control Panel")
root.geometry("500x400")  # Increased width for all buttons to fit nicely
root.configure(bg="lightgray")

# Title
title = tk.Label(root, text="Robot Controller", font=("Arial", 18, "bold"), fg="blue", bg="lightgray")
title.pack(pady=10)

# Robot Image
robot_img = tk.PhotoImage(file=r"C:\\Users\\tonyc\\Downloads\\robot.png")
img_label = tk.Label(root, image=robot_img, bg="lightgray")
img_label.pack()

# Control Frame
frame = tk.LabelFrame(root, text="Movement", font=("Arial", 12, "bold"), padx=10, pady=10, bg="white")
frame.pack(pady=15)

# Control Buttons
btn_forward = tk.Button(frame, text="Forward", width=12, bg="green", fg="white")
btn_forward.grid(row=0, column=1, pady=5)

btn_left = tk.Button(frame, text="Left", width=12, bg="orange")
btn_left.grid(row=1, column=0, padx=5)

btn_right = tk.Button(frame, text="Right", width=12, bg="orange")
btn_right.grid(row=1, column=2, padx=5)

btn_backward = tk.Button(frame, text="Backward", width=12, bg="red", fg="white")
btn_backward.grid(row=2, column=1, pady=5)

root.mainloop()
🧠 Explanation:
  • root.geometry("500x400") ensures all widgets fit comfortably.
  • bg="lightgray" gives a modern, soft background.
  • LabelFrame and Button backgrounds are styled for clarity and contrast.
  • Use padx and pady for spacing between widgets and inside frames.
