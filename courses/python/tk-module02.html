Module 2: Layouts, Frames & Action Buttons

Learn how to group controls using LabelFrame, organize widgets with grid(), and trigger real actions with buttons—laying the foundation for your robot control panel.

Step 1: Set Up the Main Window and Add a Labeled Frame

Concepts Introduced:
  • Tkinter window: Every GUI app needs a main window (also called the “root” window).
  • Window size: Use .geometry() to set its width and height in pixels.
  • LabelFrame: A frame with a border and title, used to group related widgets.
  • Force visibility: If a frame is empty, it might collapse and become invisible—so we add a placeholder label.
import tkinter as tk

# Create the main window
root = tk.Tk()
root.title("Pico Otto GUI")       # Set the window title
root.geometry("300x300")          # Set window size to 300x300 pixels

# Create a labeled frame with title and padding
movement_frame = tk.LabelFrame(root, text="Movement Controls", font=("Arial", 12),
                               borderwidth=2, relief="groove", padx=10, pady=10)

# Make sure the frame is visible even if empty
movement_frame.config(width=200, height=100)
movement_frame.pack(pady=10)  # Add some space around the frame

# Optional placeholder to keep the frame visible
placeholder = tk.Label(movement_frame, text="(Add controls here)")
placeholder.pack()

# Start the GUI loop (must be at the end)
root.mainloop()
🧠 Explanation:
  • tk.Tk() creates the main window.
  • .geometry() sets the window size.
  • LabelFrame is a frame with a border and title for grouping widgets.
  • Adding a placeholder label keeps the frame visible even if empty.

Step 2: Using .grid() to Arrange Buttons Like a D-pad

Concepts Introduced:
  • Button widgets: Basic clickable elements.
  • .grid() layout: Lets you place widgets in rows and columns (just like a table).
  • D-pad layout: Forward = top center, Back = bottom center, Left = middle left, Right = middle right.
import tkinter as tk

root = tk.Tk()
root.title("Pico Otto GUI")
root.geometry("300x300")

movement_frame = tk.LabelFrame(root, text="Movement Controls", font=("Arial", 12),
                               borderwidth=2, relief="groove", padx=10, pady=10)
movement_frame.pack(pady=10)

# Create directional buttons
forward_btn = tk.Button(movement_frame, text="↑ Forward")
left_btn = tk.Button(movement_frame, text="← Left")
right_btn = tk.Button(movement_frame, text="→ Right")
back_btn = tk.Button(movement_frame, text="↓ Back")

# Place them in a grid like a game controller
forward_btn.grid(row=0, column=1)
left_btn.grid(row=1, column=0)
right_btn.grid(row=1, column=2)
back_btn.grid(row=2, column=1)

root.mainloop()
🧠 Explanation:
  • Each Button creates a clickable control.
  • .grid() arranges widgets in a table-like layout.
  • This layout mimics a D-pad for intuitive robot control.

Step 3: Adding Functions to Buttons (Command Callbacks)

Concepts Introduced:
  • Command parameter: Makes the button do something when clicked.
  • Functions (def): Define reusable code blocks that are triggered by buttons.
import tkinter as tk

# Define actions when buttons are clicked
def move_forward():
    print("Moving Forward")

def move_back():
    print("Moving Backward")

def move_left():
    print("Turning Left")

def move_right():
    print("Turning Right")

root = tk.Tk()
root.title("Pico Otto GUI")
root.geometry("300x300")

movement_frame = tk.LabelFrame(root, text="Movement Controls", font=("Arial", 12),
                               borderwidth=2, relief="groove", padx=10, pady=10)
movement_frame.pack(pady=10)

# Buttons trigger the movement functions
forward_btn = tk.Button(movement_frame, text="↑ Forward", command=move_forward)
left_btn = tk.Button(movement_frame, text="← Left", command=move_left)
right_btn = tk.Button(movement_frame, text="→ Right", command=move_right)
back_btn = tk.Button(movement_frame, text="↓ Back", command=move_back)

forward_btn.grid(row=0, column=1)
left_btn.grid(row=1, column=0)
right_btn.grid(row=1, column=2)
back_btn.grid(row=2, column=1)

root.mainloop()
🧠 Explanation:
  • Each function defines what happens when a button is pressed.
  • command=move_forward links the button to the function.
  • Function names are passed without parentheses.

Step 5: Final GUI with Functioning D-pad

Concepts Combined:
  • Labeled frames for organization.
  • Grid layout for button positioning.
  • Commands to control robot or print movement.
  • Title for better user experience.
import tkinter as tk

# Movement functions
def move_forward():
    print("Moving Forward")

def move_back():
    print("Moving Backward")

def move_left():
    print("Turning Left")

def move_right():
    print("Turning Right")

# Main window setup
root = tk.Tk()
root.title("Pico Otto GUI")
root.geometry("300x300")

# App title
title_label = tk.Label(root, text="Pico Otto Direction Control", font=("Arial", 14))
title_label.pack(pady=5)

# Group box for controls
movement_frame = tk.LabelFrame(root, text="Movement Controls", font=("Arial", 12),
                               borderwidth=2, relief="groove", padx=10, pady=10)
movement_frame.pack(pady=10)

# Directional buttons
forward_btn = tk.Button(movement_frame, text="↑ Forward", command=move_forward)
left_btn = tk.Button(movement_frame, text="← Left", command=move_left)
right_btn = tk.Button(movement_frame, text="→ Right", command=move_right)
back_btn = tk.Button(movement_frame, text="↓ Back", command=move_back)

# Arrange like a D-pad
forward_btn.grid(row=0, column=1)
left_btn.grid(row=1, column=0)
right_btn.grid(row=1, column=2)
back_btn.grid(row=2, column=1)

root.mainloop()
🧠 Explanation:
  • This code brings together all previous steps for a working robot control panel.
  • Each button triggers a movement function and prints to the console.
  • The layout is clean, organized, and ready for further extension.
