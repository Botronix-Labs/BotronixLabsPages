🧩 Module 1: Introduction to Tkinter GUI (Step-by-Step)

🎯 Goal: Understand the basics of creating a GUI window with buttons, labels, and layout management in Python using Tkinter.

🪜 Step 1: What is Tkinter?

Tkinter is the standard Python library for creating Graphical User Interfaces (GUI). It’s included in Python by default, making it perfect for beginners.

✅ What you'll learn:
  • How to create a basic window
  • How to add widgets like Labels and Buttons
  • How to use layouts like .pack() and .grid()

🧪 Step 2: Create Your First Window

import tkinter as tk  # Import tkinter module

# Create the main window
root = tk.Tk()
root.title("My First GUI")
root.geometry("300x200")  # Width x Height

# Start the GUI loop
root.mainloop()
🧠 Explanation:
  • tk.Tk() creates a root window.
  • .title() sets the window title.
  • .geometry() sets the size.
  • mainloop() keeps the window open and responsive.

✅ Try this code — you should see a blank GUI window pop up!

🧪 Step 3: Add a Label and a Button

import tkinter as tk

root = tk.Tk()
root.title("Label and Button")
root.geometry("300x200")

# Add a Label
label = tk.Label(root, text="Welcome to Robotics!", font=("Arial", 14))
label.pack(pady=10)

# Add a Button
button = tk.Button(root, text="Click Me")
button.pack()

root.mainloop()
🧠 Explanation:
  • Label displays text.
  • Button creates a clickable button.
  • .pack() automatically places the widgets vertically.
  • pady=10 adds vertical spacing.

💡 This simple layout is enough for many robot control panels.

🧪 Step 4: Add Button Action with a Function

import tkinter as tk

def greet():
    label.config(text="Hello, Robot Builder!")

root = tk.Tk()
root.title("Robot Greeter")
root.geometry("300x200")

label = tk.Label(root, text="Welcome!", font=("Arial", 14))
label.pack(pady=10)

button = tk.Button(root, text="Greet", command=greet)
button.pack()

root.mainloop()
🧠 Explanation:
  • def greet() defines a Python function.
  • command=greet binds the button to the function.
  • .config(text="...") changes the label text dynamically.

✅ Try clicking the “Greet” button. Did the label change?

🧪 Step 5: Use Entry Field to Accept User Input

import tkinter as tk

def show_name():
    name = entry.get()
    label.config(text=f"Hello, {name}!")

root = tk.Tk()
root.title("Name Greeter")
root.geometry("300x200")

entry = tk.Entry(root, font=("Arial", 12))
entry.pack(pady=10)

button = tk.Button(root, text="Say Hello", command=show_name)
button.pack()

label = tk.Label(root, text="", font=("Arial", 14))
label.pack(pady=10)

root.mainloop()
🧠 Explanation:
  • Entry is a text box for user input.
  • .get() retrieves the text from the Entry.
  • You can use f-strings to format dynamic messages.

💬 Now you’re collecting input—perfect for robot commands later!
